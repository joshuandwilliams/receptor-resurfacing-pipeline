# tests/negative_steering/data/

Canonical inputs for `test_negative_steering.nf`. Eight MPNN sequences
spanning the observable per-MPNN-sequence outcome classes derived in
`notes/inventory/15_discovery_run_path_coverage.md` §Negative steering,
plus the parent RFDiffusion design PDBs they reference, the
`RFDIFFUSION_FILTER` metrics blob, and the input complex PDB used by
the negative-controls path.

## File-by-file

### `input_complex.pdb`

Receptor+effector complex PDB consumed by `DERIVE_INPUT_INDICES` when
`params.run_negative_controls = true` (default). Identical to
`tests/rfdiffusion/data/af3_pikp1_native_avrpikf_complex.pdb`.

### `rfdiffusion_metrics.json`

The full `RFDIFFUSION_FILTER` metrics blob (all 64 designs from the
discovery run). `NEGSTEER_DERIVE_INDICES` reads it via
`derive_design_region.py` and `derive_true_interface.py` to compute
the per-design region and true interface index files.

The blob contains entries for designs not present in `design_pdbs/` —
those entries are unused by the test (the index derivation runs
per-PDB) but we keep the blob unfiltered so the file is byte-identical
to the discovery-run output.

### `design_pdbs/design_<N>.pdb`

Parent RFDiffusion design PDBs (chain A = Cα-only designed receptor
backbone, chain B = native effector). Filename pattern
`design_<N>.pdb` — the basename keys the `combine(by: 0)` join between
FASTAs and PDBs in the workflow (`test_negative_steering.nf:236–242`).

Source: `tests/full_test_run/results/rfdiffusion/passing/`.

### `fastas/design_<N>_seq_<M>.fasta`

Combined receptor+effector FASTAs in the `>receptor` / `>effector`
shape that `bin/negative_steering_run_one.sh` expects. The orchestrator
splits each combined FASTA into separate receptor/effector files at
runtime (lines 168–198 of `modules/negative_steering.nf`).

Filename **must** match `/^design_\d+_seq_\d+\.fasta$/` — the
workflow's regex extracts the `design_<N>` stem from the filename to
join against `design_pdbs/`.

Source: `tests/full_test_run/results/sequences/top_fastas/`.

## Path coverage

See `notes/inventory/15_discovery_run_path_coverage.md` §Negative
steering for the full taxonomy and per-class verification commands.
The fixture covers Classes 1, 2, 3a, 4 (×2 — within-sequence-mixed +
clean-3/3), 5, 6, and 7. Class 3b and Class 8 are uncovered:

- **Class 3b** (mixed `no_reversion` + `pose_collapses` in the same
  sequence) — skipped as a representative-selection artefact; the
  same code paths fire as Class 7 + Class 3a together. See report
  Coverage gap 4.
- **Class 8** (`new_contamination` aggregated) — not produced by the
  discovery run at any resolution. Will be covered by a separate
  manufactured fixture or unit test, not by this fixture. See report
  Coverage gap 2.

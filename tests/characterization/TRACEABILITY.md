## Conventions

- Test naming: `test_<output>_from_<producer>` where producer is the `.py` file or function name.
- Producer column: file path relative to repo root, optionally with `::function` suffix.
- Output pinned: relative path from `reference_root`.
- Strategy: one of `CSV-EXACT`, `CSV-STRUCT`, `CSV-EXACT-MODULO-PATHS`, `JSON-DEEP`, `JSON-MODULO-PATHS`, `TEXT-EXACT`, `PNG-PERCEPTUAL`, `PNG-EXISTS`. `CSV-EXACT-MODULO-PATHS` is the shared `compare_csv_exact_modulo_paths` helper that pre-normalises every string cell via `path_normalizer` before performing CSV-EXACT comparison.

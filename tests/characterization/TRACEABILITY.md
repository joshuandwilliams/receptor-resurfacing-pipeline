# Characterization Test Traceability

This document maps each characterization test to the pipeline producer it pins. It is the canonical answer to "if I touch <file>, which tests should I expect to flicker?"

This file is updated as `hpc`-tier and `local_integration`-tier tests are added. Comparator unit tests (`local_unit`) are NOT listed here — they test the comparators themselves, not the pipeline. The lone exception is `test_rfdiffusion_filter_fail_branch_unit` (covers the predicate at `bin/rfdiffusion_filter.py:820`, a defensive code path no fixture can reach — see notes/inventory/15_discovery_run_path_coverage.md Coverage gap 1).

Reference paths are now per-module: `tests/<stage>/example_output_files/`. Output paths are per-module: `tests/<stage>/receptor_resurfacing_results/`. The deprecated single-root `tests/full_test_run/example_output_files/` is retired (the alias fixtures in conftest.py exist only to ease transition).

## Conventions

- Test naming: `test_<output>_from_<producer>` where producer is the `.py` file or function name.
- Producer column: file path relative to repo root, optionally with `::function` suffix.
- Stage column: which `STAGE_ROOTS` entry in `conftest.py` resolves the test's reference and output paths. `n/a` means the test does not bind a per-stage root (file-level skip, or local-unit predicate test).
- Output pinned: relative path from `tests/<stage>/example_output_files/`. For per-sequence parametrized tests, `<seq>` is a placeholder for SEQUENCE_COHORT (10 entries).
- Strategy: one of `CSV-EXACT`, `CSV-STRUCT`, `CSV-EXACT-MODULO-PATHS`, `JSON-DEEP`, `JSON-MODULO-PATHS`, `TEXT-EXACT`, `PNG-PERCEPTUAL`, `PNG-EXISTS`, or `import + assert` (local-unit only). `CSV-EXACT-MODULO-PATHS` is the shared `compare_csv_exact_modulo_paths` helper that pre-normalises every string cell via `path_normalizer` before performing CSV-EXACT comparison.
